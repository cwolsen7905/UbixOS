UbixOS Build Guide
==================

For full documentation see BUILDING.md in the repository root.
This file summarizes the VirtualBox VM development workflow.


VirtualBox VMs
--------------

Two VMs are used for UbixOS development:

  MrOlsen-BSD VM
    - Build host running a preconfigured BSD system.
    - SSHD enabled; VM uses DHCP (check assigned IP after start).
    - UbixOS.vdi virtual disk attached and mounted at /ubixos.
    - Start: VBoxHeadless -s MrOlsen-BSD

  UbixOS VM
    - Target system that boots from the shared UbixOS.vdi disk.
    - RDP enabled on port 3389 for desktop access.
    - Start: VBoxHeadless -s UbixOS

The 2 GB virtual disk is shared between both VMs. Do not run both VMs
with simultaneous write access.


Building
--------

SSH into MrOlsen-BSD, become root, and run:

  cd /ubixos/usr/src
  make; sync

This builds the kernel and world, installs both to /ubixos and /ubixos_fat,
and flushes all filesystem buffers.

For kernel-only changes:
  make kernel; make install-kernel; sync

For userland-only changes:
  make world; make install-world; sync


Rebooting
---------

After a kernel change: press Alt+C in the RDP session for the UbixOS VM.
After a userland-only change: no reboot needed; new processes pick up the
updated binaries immediately.


Version Control
---------------

The repository uses git. Common operations:

  git pull                  # fetch latest changes from the remote
  git commit -a             # stage and commit all tracked changes
  git add <file>            # track a newly created file before committing
  git push                  # push commits upstream (ensure it builds first)

Always verify that `make; sync` succeeds before running `git push`.
